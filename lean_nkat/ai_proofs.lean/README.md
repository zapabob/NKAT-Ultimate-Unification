# 🌟 NKAT 自動証明ワークフロー統合システム

ボブにゃんの「aesop即死0/128ｗｗｗ」を解決する自動証明エンジン  
Cursor AI + Lean 4 自動証明パイプライン  
なんJ実況テンションで証明生成・検証・学習を自動化

## 🎯 プロジェクト概要

このプロジェクトは、Lean 4を使用した自動定理証明システムです。定理の自動生成から証明の試行、結果の分析まで、完全自動化されたワークフローを提供します。

### 🏆 主要機能

- **🎲 定理ガチャ**: 自動定理生成システム
- **🎯 証明トレーナー**: 自動証明試行システム  
- **🧠 戦略学習システム**: 証明戦略の自動学習・推薦
- **📊 結果解析**: 成功率・タクティック別統計
- **🛡️ 電源断保護**: 自動チェックポイント・緊急保存
- **🔄 ワークフロー統合**: Python + Lean 4 自動化

## 🚀 クイックスタート

### 環境セットアップ

```powershell
# Lean 4環境確認
$env:PATH = "C:\Users\downl\.elan\bin;$env:PATH"

# プロジェクトビルド

```

### 個別実行

```powershell
# 定理ガチャ実行
lake exe conjecture_generator_simple Main.lean 20 ./conjectures

# 証明トレーナー実行  
lake exe proof_trainer_simple Main.lean 20 ./proofs/proof_results.txt
```

### 統合ワークフロー実行

```powershell
# Python統合スクリプト実行
py -3 cursor_integration.py 20 20
```

## 🎮 システム詳細

### 定理ガチャ (conjecture_generator_simple)

- **機能**: 自動定理生成
- **出力**: JSON形式の定理ファイル
- **なんJテンション**: ガチャ感覚の定理生成

```lean
-- 例: 定理生成
theorem example_theorem (n : Nat) : n + 0 = n := by
  simp
```

### 証明トレーナー (proof_trainer_simple)

- **機能**: 自動証明試行
- **タクティック**: simp, aesop, cases
- **出力**: テキスト形式の結果レポート
- **なんJテンション**: 証明成功・失敗の実況

```
🎯 証明成功！simp (1.000000s)
💀 証明失敗... aesop failed: no proof found
```

### 戦略学習システム (proof_strategy_learner.py)

- **機能**: 証明戦略の自動学習・推薦
- **分析**: タクティック性能・定理パターン分析
- **可視化**: 戦略分析グラフ生成
- **推薦**: 最適タクティック自動推薦

### Python統合スクリプト (cursor_integration.py)

- **機能**: 完全ワークフロー統合
- **電源断保護**: 5分間隔自動保存・緊急保存
- **セッション管理**: 固有IDでの完全追跡
- **バックアップ**: 最大10個の自動管理
- **戦略学習**: 統合戦略学習機能

## 🛡️ 電源断保護機能

### 自動チェックポイント保存
- **間隔**: 5分間隔での定期保存
- **形式**: JSON + Pickleによる複合保存
- **場所**: `checkpoint_YYYYMMDD_HHMMSS.pkl`

### 緊急保存機能
- **トリガー**: Ctrl+C, SIGTERM, SIGBREAK
- **処理**: 即座にデータ保護
- **バックアップ**: 緊急時専用バックアップ作成

### 復旧システム
- **自動復旧**: 前回セッションからの自動復旧
- **データ整合性**: 複合保存による完全性保証
- **セッション追跡**: 固有IDでの完全なセッション管理

## 📊 結果分析

### 成功率統計
- **全体成功率**: 全証明試行の成功率
- **タクティック別**: 各タクティックの成功率
- **時間分析**: 証明時間の統計

### 出力例
```
📊 統計情報
   🎯 成功率: 50.00%
   📈 成功数: 10/20
   
🎲 タクティック別統計:
   simp: 60.00% (3/5)
   aesop: 40.00% (2/5)  
   cases: 50.00% (5/10)
```

## 🔧 技術仕様

### Lean 4環境
- **バージョン**: v4.21.0

- **バージョン**: Python 3.12+
- **依存関係**: 標準ライブラリのみ
- **エンコーディング**: UTF-8

### ファイル形式
- **定理ファイル**: JSON

- **チェックポイント**: Pickle + JSON
