## 1. コラッツ予想の一般化数学的定式化

### 1.1 古典的コラッツ予想

古典的コラッツ予想は、任意の正整数 n に対し、以下の操作を繰り返すと必ず1に到達することを主張する：

$$f(n) = \begin{cases}
n/2 & \text{if } n \text{ is even} \\
3n + 1 & \text{if } n \text{ is odd}
\end{cases}$$

### 1.2 一般化コラッツ予想

一般化コラッツ予想では、パラメータ k, m, b を導入：

$$f_{k,m,b}(n) = \begin{cases}
n/b & \text{if } n \equiv 0 \pmod{b} \\
kn + m & \text{if } n \not\equiv 0 \pmod{b}
\end{cases}$$

ここで：
- k: 奇数時の乗数 (k > 1)
- m: 奇数時の加数 (m > 0)
- b: 基数パラメータ (b > 1)

### 1.3 非可換拡張コラッツ予想

NKAT理論により、非可換コラッツ写像を導入：

$$f_{\text{NC}}(n) = \begin{cases}
n/b + \theta \cdot n & \text{if } n \equiv 0 \pmod{b} \\
kn + m + \theta \cdot (kn + m) & \text{if } n \not\equiv 0 \pmod{b}
\end{cases}$$

### 1.4 統合特解拡張コラッツ予想

統合特解理論により、リーマンゼータ零点スペクトルを活用：

$$f_{\text{unified}}(n) = f_{\text{NC}}(n) + \sum_q \lambda_q^* \cdot \text{correction}_q(n)$$

ここで $\lambda_q^* = \frac{1}{2} + it_q$ はリーマン零点である。
